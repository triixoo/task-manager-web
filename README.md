# Task Manager

[Open Task Manager](https://triixoo.github.io/task-manager-web/)

A browser task manager by Karaul Shyngys and Daniar Aitanov. Create tasks, assign team members, set deadlines and priorities, and track progress.

This repository contains the generated static website, compiled from Java with TeaVM 0.16.0. Data saves in your current browser; there is no shared cloud workspace. Use Export backup to keep a copy or transfer work to another device.

Built from source commit `081fdf4` after 15 Java scenarios and 13 browser scenarios passed. GitHub Pages publishes the root of the main branch.
