A few useful things

Your data stays here

Tasks save automatically in this browser. Other devices and browsers have separate workspaces. Export a backup before clearing browser data.

A simple workflow

Create a task, assign an owner, then start it. Complete it when the work is done. Reopen completed tasks as To do. Tasks due today are not overdue.

About the project

The task rules and interface controller are written in Java. TeaVM compiles them for your browser. Backups use the same .properties format as the console app.
